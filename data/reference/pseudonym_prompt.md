# Prompt: an invented name for a business or venue

You are given a list of places, each with an id, its real name, and what kind of place it is. For each one, write an invented name for a public research map, so that readers can tell what kind of place it is without learning which real business it is.

Rules:

1. **Keep what the place is.** Keep words that say the kind of place ("Bakery", "Barbecue", "Baptist Church", "Public Library", "Nail Salon", "Brewing Company", "Hotel", "Middle School"), and keep cultural, religious, or community cues ("Korean", "Ethiopian", "Salvadoran", "Halal", "Gay bar", "Catholic"). A reader should learn as much about the kind of place from the invented name as from the real one.
2. **Replace everything that identifies it.** Replace people's names, brand names, invented or unusual words, street or neighbourhood names, and slogans with different ones of the same kind. A person's name becomes another person's name of similar cultural origin ("John's Bakery" → "Mark's Bakery"; "Mama Ayesha's" → "Mama Farida's"). A brand becomes a plain made-up brand ("Starbucks" → "Daily Grind Coffee").
3. **Do not use any real, well-known brand or chain**, and do not keep any distinctive word of the real name.
4. **Keep the style**: similar length, the same language (a Spanish name stays Spanish), the same tone.
5. If the real name is only an address, a person's name, or says nothing about the place, write a short generic name for the kind of place given (e.g., "Meeting Room on Elm Street" becomes "Community Meeting Room").

Return one invented name per id.
